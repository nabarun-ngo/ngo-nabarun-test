TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

ISSUE 1: Project doesn't recognize as Maven project
─────────────────────────────────────────────────────
  SOLUTION:
    a) File → Project Structure → Project
    b) Click "+" next to Modules
    c) Select: Import Module from External Model → Maven
    d) Choose pom.xml from project root

ISSUE 2: Red error marks on source files
──────────────────────────────────────────
  SOLUTION:
    a) File → Invalidate Caches / Restart
    b) Choose: Invalidate and Restart
    c) Wait for IntelliJ to reindex (check bottom right)
    d) Maven panel → Reload Projects

ISSUE 3: Dependencies not found
─────────────────────────────────
  SOLUTION:
    a) File → Settings → Build → Maven → Repositories
    b) Find "central" repository
    c) Click "Update" button
    d) Delete Maven cache:
       PowerShell: Remove-Item -Path "$env:USERPROFILE\.m2\repository" -Recurse -Force
    e) Try building again: mvn clean install

ISSUE 4: Java version mismatch
───────────────────────────────
  SOLUTION:
    a) File → Project Structure → Project
    b) Set Project SDK to Java 17
    c) File → Project Structure → Modules
    d) Set Language level to Java 17
    e) Rebuild: Build → Clean Build Project

ISSUE 5: Source folders not recognized
────────────────────────────────────────
  SOLUTION:
    a) File → Project Structure → Modules
    b) Click on: ngo-nabarun-test
    c) Click: Sources tab
    d) Verify source folders are marked:
       - src/main/java        → Sources
       - src/main/resources   → Resources
       - src/test/java        → Tests
       - src/test/resources   → Test Resources
    e) If not, select folder and mark accordingly
